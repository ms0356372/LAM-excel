# Excel 管理級數整理工具 V2.0

Windows 桌面工具，使用 CustomTkinter 與 Excel COM（`pywin32`）整理健康檢查或管理級數資料。V2.0 延續 V1 的 ColorIndex 分級流程，並在同一個 GUI 新增可保存規則的「自訂分級」。程式需在已安裝 Microsoft Excel 的 Windows 電腦執行。

## 功能模式

### 1. 依顏色分級（V1 相容）

此模式仍直接讀取 Excel 原生 `cell.Interior.ColorIndex`，映射與 V1 完全相同：

| ColorIndex | 結果 |
|---:|---|
| -4142 | 第一級 |
| 34 | 第二級 |
| 6 | 第三級 |
| 3 | 第四級 |

其他顏色及空白儲存格不處理。結果依來源欄由左至右，以 `表頭；` 寫入第一級至第四級欄。舊的掃描函式、ColorIndex 取得方式與映射常數保留不變。

### 2. 自訂分級

依儲存格實際內容套用 GUI 中的規則，支援：

- 區間（包含上下限）
- `>`、`>=`、`<`、`<=`
- 完全相符（移除前後空白後 exact match，不做模糊搜尋）
- 共用、男、女三種條件
- 規則新增、編輯、刪除、上移、下移、重新整理（下方操作區是唯一新增入口）
- 使用 `ttk.Treeview` 的規則表格檢視（順序、欄位、表頭、性別、判斷方式、條件、分級、狀態）
- 規則搜尋，以及性別、分級、狀態的組合篩選
- 共用既有衝突檢查結果的規則狀態與警告提示
- 維持實際判斷順序的只讀表格型規則總覽（支援搜尋及性別、分級、狀態篩選）
- JSON 自動保存、另存與載入

同一欄位先依資料列的性別測試專用規則；專用規則沒有命中時才測試共用規則。各群組依畫面順序採 **first match wins**。若性別空白或不是男／女，只會使用共用規則。含男／女規則時，第一列必須有完全相同的 `性別` 表頭；它可以位於分析範圍之外。

數值、整數及數字文字（含前後空白）都會轉成數值比較。空白直接跳過，無法轉換的文字視為不符合且計入統計。規則重疊可以保存，介面會提醒實際結果由規則順序決定。

### 規則衝突檢查

- 新增或編輯規則儲存時，只比較**相同來源欄位、相同性別群組**的規則。
- 系統會精確檢查數值區間與開放／封閉邊界，例如 `>10` 與 `>20`、`1～10` 與 `>8` 會重疊，但 `1～10` 與 `>10` 不重疊。
- 完全相符內容相同時視為重疊；內容不同時不衝突。
- 欄位、性別、運算子、條件及分級全部相同時，會顯示「此規則已存在」並拒絕重複保存。
- 相同條件指定不同分級時會顯示明確警告；一般重疊也會列出目前規則與衝突規則，使用者確認後仍可保存。
- 男／女專用規則與共用規則可能同時命中時屬於覆寫提醒，不列入同群組衝突；專用規則維持優先。
- 規則列表以 `⚠` 標出同群組衝突。按下「開始自訂分級」時會再次顯示衝突組數，使用者可繼續或取消。

### 規則列表與規則總覽

規則列表預設嚴格按照規則 JSON／程式內 `rules` 清單的正式順序顯示，不提供會改動資料順序的欄名排序。搜尋可比對欄位、表頭、性別、判斷方式、格式化條件及分級；所有篩選只影響畫面。雙擊表格列會開啟既有的編輯規則視窗，新增、編輯、刪除及上下移後會立即更新列表。存在的規則一定生效；若不再使用，請直接選取並刪除。

「規則總覽」是使用 `ttk.Treeview` 的只讀單一視窗，欄位為順序、欄位、表頭、性別、判斷方式、條件、分級與狀態，並嚴格維持原始 first match wins 順序。它可搜尋欄位、表頭、性別、判斷方式、條件、分級與狀態，亦可依性別、分級、狀態篩選。列表與總覽使用相同的條件格式化及既有衝突／覆寫檢查；修改規則仍須回到主畫面。

## Excel 格式與輸出

1. 支援 `.xlsx`、`.xlsm`、`.xls`；`.xlsm` 會維持巨集格式。
2. 第一列必須是表頭，並包含完全相同的 `管理級數`。
3. 分析範圍必須採 `M1:R2000` 形式並由第 1 列開始。
4. 程式會在 `管理級數` 後建立或重用 `第一級`、`第二級`、`第三級`、`第四級`，執行前清除舊結果。
5. 自訂模式的每個規則欄位都必須位於分析範圍，否則執行會停止並顯示欄位名稱。
6. 同列同級的項目依來源欄由左至右排列，同一表頭只寫入一次。
7. 建議先關閉活頁簿並備份原始檔；程式預設另存為 `原檔名_整理完成`。

## 規則保存

開發環境預設寫入專案根目錄的 `custom_rules.json`；打包版寫入 `%APPDATA%\Excel管理級數整理工具\custom_rules.json`，避免單檔 EXE 的暫存目錄問題。格式版本為 1，例如：

```json
{
  "version": 1,
  "rules": [
    {"column": "M", "gender": "共用", "operator": "range", "minimum": 1.0, "maximum": 10.0, "level": "第一級"},
    {"column": "N", "gender": "男", "operator": ">=", "value": 90.0, "level": "第三級"},
    {"column": "O", "gender": "共用", "operator": "exact", "value": "++", "level": "第二級"}
  ]
}
```

檔案不存在時以空規則啟動；JSON 損壞或內容無效時顯示警告，主程式仍會以空規則啟動。載入舊 JSON 時，`enabled: true` 正常載入，`enabled: false` 視為已刪除並忽略，介面會顯示忽略筆數；新版保存不再寫入該欄位。

## 規則 Excel 匯入與匯出

「匯出 Excel」會依正式的 first match wins 順序匯出全部規則，不受列表搜尋或篩選影響。`規則` 工作表欄位固定為：順序、欄位、表頭、性別、判斷方式、下限、上限、判斷值、分級、備註、檢查結果；另附「填寫說明」及格式版本。性別、判斷方式與分級具有下拉選單。沒有規則時可直接產生 `自訂分級規則範本.xlsx`。

「匯入 Excel」接受上述前九個核心欄位，備註與檢查結果可省略，未知的未來欄位會忽略。舊版 Excel 若仍有「啟用」欄，是／TRUE／1 正常匯入，否／FALSE／0 直接忽略。空白列也會忽略。程式先檢查格式、數值條件及既有衝突，再顯示逐列預覽和正常／警告／錯誤統計，絕不在選檔後直接修改規則：

- **錯誤**：核心欄位缺少、順序或欄位格式錯誤、非法性別／判斷方式／分級、數值無法解析、區間上下限顛倒、完全相符內容空白等。只要存在錯誤便不能匯入。
- **警告**：表頭空白或與目前資料不一致、順序重複／不連續、規則重疊、完全重複、相同條件不同分級、男女專用與共用規則重疊。只有警告時仍可由使用者確認匯入。

「取代」會在第二次確認後以 Excel 規則替換全部規則；「合併」會保留現有規則、加入 Excel 規則，並對合併後整體再次執行相同衝突檢查。正式寫入前保留記憶體備份，儲存或更新期間若發生例外，會回復原規則，確保 all-or-nothing。JSON 備份／載入功能仍維持不變，Excel 功能不取代 JSON。

## 安裝與執行

請使用 Windows、Python 3.10+ 並安裝 Microsoft Excel：

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

主畫面上方選擇 Excel、工作表和輸出位置，再切換「依顏色分級」或「自訂分級」頁籤。兩個頁籤各有對應的使用說明；下方共用進度條與執行紀錄。

## EXE 打包

直接雙擊：

```text
build_exe.bat
```

批次檔會安裝 `requirements.txt`、使用 `Excel管理級數整理工具.spec` 執行 PyInstaller、驗證成品並輸出：

```text
release\Excel管理級數整理工具.exe
```

`build`、`dist` 只在失敗時保留以供除錯。目標電腦仍需安裝 Microsoft Excel。

## 測試

跨平台的規則引擎與 JSON 測試：

```bash
python -m pytest -q
python -m py_compile main.py rule_models.py rule_engine.py config_manager.py
```

測試涵蓋區間邊界、嚴格比較、exact match、無效數字、空白、男女優先、共用 fallback、first match wins、舊格式相容、驗證、JSON 損壞，以及規則條件格式、搜尋、篩選與狀態彙整。Linux CI 無法啟動 Windows Excel COM，因此仍需在 Windows 實機驗證：

1. 四種 V1 ColorIndex 的輸出與既有檔案結果完全一致。
2. 新增四個結果欄及已存在時重用、清除舊結果。
3. 管理級數位於來源範圍前方時，插欄後來源欄位仍正確位移。
4. 性別欄位在分析範圍外仍能套用男女規則。
5. `.xlsx`、`.xlsm`、`.xls` 另存，尤其 `.xlsm` 巨集保留。
6. `build_exe.bat` 可產生並啟動 release EXE，規則可在重啟後載入。
7. 規則列表搜尋／篩選、雙擊編輯、刪除及上下移皆即時更新，顯示順序與實際判斷順序一致。
8. 規則總覽只能開啟一個；表格、搜尋、性別、分級與狀態篩選正確，且不修改任何規則。
9. 切回依顏色分級後，V1 ColorIndex 流程及輸出結果不受影響。
